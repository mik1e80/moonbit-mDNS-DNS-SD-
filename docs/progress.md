## 开发与提交规则

- 每个独立且有意义的实现步骤提交，并推送指定 GitHub 仓库。
- 不使用空提交、改写日期或机械拆分文件制造提交数量。
- 用户要求轻量测试：当前包检查、少量关键断言和短时冒烟；不反复全量跑所有后端。
- 如本地或远端检查未执行，明确标为未验证。

## 已完成

- 创建 MoonBit 模块骨架和 Apache-2.0 许可证。
- 保存原始实施计划，明确首版范围、场景和已有生态差异。
- 固定项目内工具链 moon 0.1.20261023、moonc v0.10.17+d971670cd，async 0.22.5；未改全局旧工具链。
- 完成 codec 复用评估，选择有限 wire 子集，记录理由和固定源码来源。
- 实现标签字节与 TXT、有限报文解码、QM 查询编码，公开根包 API 和离线示例。
- 实现最小 Native IPv4 socket 扩展，提供入站接口与目标地址；同机 python-zeroconf 组播互通通过。
- 本地按改动分批通过共 9 个轻量测试；首轮 GitHub 轻量 CI 通过，包括 Windows/Linux 编译。

## 当前风险

- 单播未收到，不能声称单播已可靠；原始实验退出码为 1，报告保留该失败检查。
- 入站 IP TTL、跨接口接纳策略、真实接口失效/独占绑定错误、第二设备互通仍待验证。
- Native 接收目前是最长 1000ms 的同步轮询接口，未接入异步取消和事件循环。
- 缓存、服务聚合、查询退避、状态事件、正式 CLI 与完整回放仍未实现。
