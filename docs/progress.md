## 已完成的连续步骤

- 固定 MoonBit `moon 0.1.20261023` / `moonc v0.10.17+d971670cd` 与 async `0.22.5`，保留全局旧工具链。
- 建立纯核心与 Native 网络适配层边界，完成模型、有限 codec、缓存、聚合、调度、resolve 和公开 API。
- 实现 browse/resolve/doctor/replay、实时 JSONL、记录时间与随机种子的 capture、可离线复现的 Replay。
- 使用独立 python-zeroconf 进程发布受控 HTTP 服务；实际发现动态端口、请求并验证 HTTP body、观察 TXT 更新与 goodbye、验证异步取消后 socket 可重开。
- 修复实网发现的 stdout 延迟输出和同一毫秒内 TXT 到达次序问题；避免空闲定时 tick 反复重建服务状态。
- 在提交 `f2baff7` 的干净工作树上，录制与回放实验的 8 项检查全部通过，包括确定性回放与实网服务事件序列一致。
- 分别修复同 tick 移除原因归属与超长 UDP 导致浏览退出的问题，保存小范围回归和实网证据。
- 完成浏览器离线回放、发布归档检查与 Mooncakes 发布；注册表下载散列与发布归档一致，116 个安装文件逐一匹配。
- `v0.1.0` 指向发布源码 `2b922d6`，对应 GitHub CI 成功；后续文档提交仅补入发布完成后获得的记录。
- 2026-10-28：保存并搁置未完成 NSEC 实验；容量与异常 PTR flush 均用先失败后通过的回归复现并修复。
- 修复 Linux 录制目录及失败诊断，扩大工作流触发路径；[40645501957](https://github.com/mik1e80/moonbit-mDNS-DNS-SD-/actions/runs/40645501957) 的八项 Avahi 检查通过。

## 验证与提交约定

每个独立且有意义的行为、修复或文档成果分别 commit 并推送指定 GitHub 仓库；不使用空提交、改写日期或机械拆分制造数量。按用户要求只进行针对当前变化的轻量测试，不反复全量运行所有后端和互通组合。已执行与尚未执行的验证分开记录。
