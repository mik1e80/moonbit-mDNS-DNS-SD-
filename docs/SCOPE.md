## 传输范围

Native Browser 仅接纳源端口 5353、目标组播地址 `224.0.0.251`、所选入站接口的响应。单播不在当前适配层范围。发送使用组播 TTL 255；不暴露接收 IP TTL。收到所选接口的组播响应不按 IP TTL 非 255 一概拒绝。

接口地址或索引失效时报告错误；不自动迁移到其他接口。底层提供有界同步 poll，异步 `run` 以短周期协作轮询并在取消时释放资源，尚未接入原生异步 fd 事件源。

## 数据与资源边界

- 名称标签为 1..63 字节；mDNS 完整 wire 名称最多 256 字节（含根终止字节）。
- 单报文最多 9000 字节，问题和 RR 合计最多 256，单名称解码最多 256 步。
- 默认缓存 2048 条、服务 512 个、事件 256 个、查询任务 256 个、订阅最多 64 个；部分容量可在 Engine 构造时调整。
- 最新同批中存在多个冲突 SRV/TXT 时标为未完成；尚无完整 SRV 优先级与权重选择。
- replay 文件上限 8 MiB/10000 帧，单行 32768 字符；录制队列溢出时拒绝保存不完整 trace。

## 暂未实现或未验证

未实现发布者、自动重命名、IPv6 组播、跨子网/反射器、后台守护进程、自动枚举所有类型、服务子类型、NSEC 负缓存、多包 Known-Answer、接口自动切换。没有 Avahi、第二台设备或 Linux 实网互通证据。

解码 AAAA 不代表支持 IPv6 传输。未见响应只表示观察窗口内未发现；TTL 到期只表示已有缓存证据失效，不证明设备离线。原始计划中的完整平台/RFC 验收不能据此标为全部完成。
